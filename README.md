Um simulador educacional no estilo *Tycoon* focado no gerenciamento de uma carreira na área de tecnologia. O jogador assume o papel de um programador *freelancer*, resolvendo contratos reais de lógica de programação para ganhar dinheiro, evoluir e otimizar seu setup.

Este projeto é desenvolvido como Trabalho de Conclusão de Curso (TCC) para o curso de **Sistemas de Informação (BSI)** da **FATEF** (Faculdade de Tecnologia de Franca).

## 🎮 Sobre o Jogo

O **Projeto Tycoon** gamifica o aprendizado de programação. Através de um sistema procedural de contratos e missões, o jogador precisa ler, entender e corrigir algoritmos em um ambiente que simula uma interface de desenvolvimento e um sistema operacional de trabalho.

O objetivo principal é ensinar e fixar conceitos lógicos (como condicionais `if/else`, laços de repetição `while/for`, variáveis e sintaxe estruturada) sem que o jogador perceba que está estudando, utilizando o ciclo viciante de recompensa financeira e evolução de hardware clássico do gênero *Tycoon*.

## ✨ Funcionalidades Principais

* **Quadro de Contratos Dinâmico:** Um sistema procedural gerencia a chegada de ofertas de *freelances* em tempo real. Cada contrato tem sua própria dificuldade, recompensa e exigência de código.
* **Sistema de Matriz de Código:** O jogo conta com um renderizador flexível que monta linhas de código interativas na tela de forma fidedigna a um editor real (como o Visual Studio), suportando identação e múltiplas linhas estruturadas.
* **Preenchimento de Lacunas (Drag & Drop):** Missões onde o jogador precisa arrastar blocos de comandos sorteados aleatoriamente para completar funções inacabadas e fazer o algoritmo funcionar.
* **Code Review (Validação de Bugs):** O jogador atua como um Revisor de Código Sênior, precisando ler um script completo, encontrar os bugs ocultos e reportá-los sem atingir o limite de erros estipulado pelo cliente (Regra da Justa Causa).
* **Economia e Feedback:** Um sistema de cálculo de honorários que recompensa o jogador pelo sucesso, aplica multas por trechos incorretos entregues e gerencia o saldo bancário.

## 🛠️ Tecnologias Utilizadas

* **Interface (UI):** Unity UI (Canvas, Layout Groups, Content Size Fitters) e TextMeshPro
